## ✨ Características Principales

- **Gestión de Reservas:** Permite a los clientes reservar mesas en tiempo real seleccionando fecha y hora.
- **Panel Administrativo:** Control de disponibilidad de mesas, visualización de estado y gestión interna.
- **Arquitectura Cliente-Servidor:** Backend desacoplado que expone una API REST para el consumo del frontend.

## 🛠️ Tecnologías Utilizadas

- **Backend:** Java, Spring Boot (Spring Web, Spring Data JPA)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
- **Base de Datos:** MySql
- **Gestor de Dependencias:** Maven

## 🚀 Requisitos Previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:
- **Java JDK** 21
- Un navegador web moderno.

## 💻 Instalación y Uso

### 1. Clonar el repositorio
```bash
git clone https://github.com
cd proyecto_TFG
```

### 2. Configurar el Backend (Spring Boot)
1. Abre el proyecto en tu IDE preferido (IntelliJ IDEA, Eclipse, VS Code).
2. Configura tus credenciales de base de datos en el archivo `src/main/resources/application.properties`.
3. Ejecuta la aplicación mediante tu IDE o con el comando:
   ```bash
   ./mvnw spring-boot:run
   ```
   *El servidor backend iniciará en `http://localhost:8080`.*

### 3. Ejecutar el Frontend
1. Ve a la carpeta donde se encuentran los archivos web (`index.html`).
2. Abre el archivo `index.html` directamente en tu navegador o levántalo con una extensión de servidor local (como *Live Server* en VS Code).
